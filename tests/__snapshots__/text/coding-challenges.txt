Coding challenges
Practise JavaScript with short puzzles from CodeWars, picked for our meetups. Pair up with someone, start with the 8 kyu challenges and talk through your solution as you go: explaining your thinking is half the practice.
CodeWars ranks challenges in kyu: 8 kyu is the easiest, and the number goes down as the challenges get harder. Create a free account on CodeWars to run your code against the tests and keep track of what you have solved.
Prefer a guided course? freeCodeCamp's JavaScript curriculum (opens in a new tab) and Full Stack Developer curriculum (opens in a new tab) teach the same skills step by step, with projects to build along the way.
